# Public GNM Head v3 integration

This checkpoint targets Google Head v3 provisionally. The evaluator target is
unconfirmed. The verified MakeHuman fallback remains available as
apollo-v0.3.0-rc.2.

## Source pin

Use Blender 4.5.15 LTS and Python 3.12 for the upstream build environment.
The upstream source is google/GNM at
f84cdbdc86a34f55627526f137495f864e687679. The Head model comes from
google/gnm-v3 at revision c01e90d298d82301f9fd18f54806be751775cb7c. The
exporter downloads the pinned file if absent and verifies its SHA-256.
The source repository and model card declare Apache-2.0. The texture sources
are CC0 and credited in assets/photorealism-v2/ATTRIBUTION.md. Retain upstream
license and notices before redistributing a derived scene.

Install gnm/shape from that source revision into a Python 3.12 environment.
The texture build uses the project requirements plus SciPy 1.15.3 in the
host Python environment. The archive includes the MakeHuman source scene
and attributed source maps needed to repeat the transfer.
Example commands from the Apollo worktree:

```powershell
git clone https://github.com/google/GNM.git out/google-gnm
git -C out/google-gnm checkout f84cdbdc86a34f55627526f137495f864e687679
python -m pip install -r requirements.txt scipy==1.15.3
uv venv --python 3.12 out/gnm-env
uv pip install --python out/gnm-env/Scripts/python.exe ./out/google-gnm/gnm/shape
& out/gnm-env/Scripts/python.exe tools/gnm_template.py --model out/gnm_head.npz --out out/template
& $env:BLENDER_BIN -b --factory-startup --python-exit-code 1 -P tools/gnm_import.py -- --template out/template/template.npz --out out/template/neutral.blend
python tools/submission_variants.py generate out/variants --polished-reference
& $env:BLENDER_BIN -b --factory-startup milestones/eye-expression-2026-11-11/scene.blend --python-exit-code 1 -P tools/gnm_skin_trial.py -- --gnm out/template/neutral.blend --variant out/variants/rose-brown/variant.json --out out/raw/color.1001.png --mouth-lift .014
New-Item -ItemType Directory out/trial -Force | Out-Null
python tools/gnm_skin_fill.py --template out/template/template.npz --bake out/raw/color.1001.png --out out/trial/color.1001.png
python tools/gnm_eye_maps.py --variant out/variants/rose-brown --out out/trial
foreach ($layout in 'udim','legacy') {
    & $env:BLENDER_BIN -b --factory-startup out/template/neutral.blend --python-exit-code 1 -P tools/gnm_texture_trial.py -- --maps out/trial --layout $layout --out "out/trial/$layout.png"
}
& out/gnm-env/Scripts/python.exe tools/gnm_gaze_trial.py --model out/gnm_head.npz --out out/gnm-gaze
```

## Evidence and remaining work

The neutral import preserved 17,821 vertices, 17,662 quads and both upstream
corner UV arrays exactly. The native evaluator produced bilateral pupil
movement in the expected directions for five gaze anchors. The front
renders using the two coordinate layouts differed by at most one 8-bit RGB
level. The trial samples separate images from the appropriate UDIM offsets.

The first aligned skin projection covered 65.4% of the rasterized skin UV
mask. Nearest-texel fill is for diagnosis. The maximum fill distance inside
the mask was 333 pixels at 2048 resolution, so this fails the texture
qualification gate. Fit regional correspondence before scaling to five
variants. Native blink fit, packed motion, full frame runs, archive and
publication remain pending.

A projection cage sweep at 1024 resolution improved raw skin coverage to
99.952% at 35 mm, with a maximum in-mask repair distance of 7.1 pixels.
The 55 mm trial covered the whole mask, but a wider projection increases
the risk of sampling the wrong surface near folds. The 35 mm setting is the
current trial default. Front previews still need stronger facial detail and
a check for misplaced texture around the lips and lids.

The Left gaze clip now evaluates 192 frame indices through the upstream
NumPy model and saves a Blender timeline. Evaluated vertices at frames 1,
23, 26 and 192 matched the upstream arrays within one micrometer in model
units before save. This trial includes gaze only. Native blink, textured
timeline rehearsal, five qualified variants and submission packaging remain
pending.

The Generate Motion trial now fits blink coefficients independently to the
two GNM eyelid rims. The right eye follows the left by one frame. Camera
rays found zero visible pupil vertices in either eye at frames 106 and 107
and found both pupils visible before closure and after reopening. Blender
matched the upstream pose arrays at seven anchor frames before saving.
This checks camera occlusion. Rendered lid contact and cornea intersection
still require inspection.

## Textured timelines

Use the timeline installer with a clip generated by the upstream NumPy
evaluator. Run the texture tool on that animation with
`--save-scene expression.blend --save-only --eye-crop --size 1024 --samples 32`
and the rose-brown maps directory. The saved scene packs the maps and includes
the exact geometry pose index for each frame. Use submission_render.py on the
saved scene with `--reuse-holds` to render each distinct pose at full quality
and populate all 192 frame numbers. Keep the same flags when resuming.

Close renders showed both pupils covered at peak blink and visible again
after reopening. The closure crease is uneven in places, and the viewing
check does not prove that the lid surface avoids all cornea intersections.
A 14 mm local lift of the disposable MakeHuman mouth source aligned the lip color with the GNM mouth seam in the front preview. This leaves the GNM mesh and both UV layouts unchanged. The 2048-pixel skin bake still needs nearest-texel repair for 0.144% of
masked texels, with a maximum repair distance of 26.6 pixels.


## Verify and reproduce the technical bundle

After extracting the archive, use Blender 4.5.15 LTS from the extracted
directory. The neutral scene, packed timelines, and color maps work with
Blender alone. The upstream Python environment is only needed to generate
geometry from the pinned model.

```powershell
& $env:BLENDER_BIN -b --factory-startup model/neutral.blend --python-exit-code 1 -P tools/gnm_texture_trial.py -- --maps textures/rose-brown --out reproduced.png --size 1024 --samples 32
& $env:BLENDER_BIN -b --factory-startup timelines/left/expression.blend --python-exit-code 1 -P tools/gnm_verify.py -- --template model/template.npz --clip timelines/left/geometry.npz --maps textures/rose-brown --out reopened.json
& $env:BLENDER_BIN -b --factory-startup timelines/left/expression.blend --python-exit-code 1 -P tools/submission_render.py -- --out reproduced-frames --first 21 --last 22
```

For day-to-day use, the extracted archive has one command for all four modes:

```powershell
python tools/gnm_run.py still --blender $env:BLENDER_BIN --variant golden-hazel --out still.png
python tools/gnm_run.py left --blender $env:BLENDER_BIN --out rendered-left
```

Use the same motion command to resume. Replace left with right or
generate-motion to select a different packed timeline. Add --first and --last
for a short sample. For stills, --layout legacy selects the region bindings.

The reopened timeline verifier checks both stored UV arrays, polygon
connectivity, region assignments, packed texture bytes and all 192 evaluated poses against the
geometry generated with the pinned Google model. It also checks bilateral screen direction and pupil occlusion at the saved camera. Build the archive from
qualified candidate output directories using:

```powershell
python tools/gnm_bundle.py --motion out/gnm-aligned-motion --textures out/gnm-aligned --template out/template --license out/google-gnm/LICENSE --out out/apollo-gnm-technical.zip
```

## Eyelid refinement after rc.3

The current source fits anterior contact depth as well as vertical lid
closure, penalizes adjacent orbital displacement differences, and constrains
all eye expression coefficients to the documented -3 to +3 range.
The bilateral closed-rim vertical spread decreased from about 2.22 mm to
1.72 mm. The 95th-percentile adjacent orbital displacement jump increased
slightly, so a flatter contact line does not establish overall surface
smoothness. Both pupils remain occluded at frames 106 and 107 and visible
before closure and after reopening. The diagnostic frames and metrics are
under milestones/gnm-blink-refinement. The published rc.3 archive contains
the prior fit. Three-mode rerender and archive requalification remain pending.

A five-value regularization sweep selected 0.5 for the orbital displacement
penalty. Compared with the rc.3 fit, closed-rim vertical spread falls from
about 2.22 mm to 1.96 mm and the 95th-percentile neighboring displacement
jump falls from about 0.94 mm to 0.73 mm. Expression coefficients remain
within ±3. All three revised packed timelines pass every-frame geometry,
packed texture, region UV and saved-camera direction/closure checks on
reopen. The sweep and receipts are under milestones/gnm-blink-refinement.
A narrow dark contact line remains visible in one lid at peak closure.
Full rendered requalification uses out/gnm-blink-final.

The extracted runner now accepts --variant and --layout for motion as well
as stills. For example, use python tools/gnm_run.py left --variant golden-hazel
--layout legacy --blender <blender.exe> --out <frames-directory>. Non-default
bindings are packed into a cached timeline under the output directory. The
cache identity includes the source scene, all three map hashes and UV layout;
its receipt verifies the saved scene before reuse. The original rig, camera,
lighting and timeline remain intact. Resume therefore uses the exact saved
variant scene rather than a newly saved file on each invocation. Archive
rehearsal checks golden-hazel in both layouts, every-frame native geometry,
packed maps, identical layout renders and preservation of valid resumed frames.
